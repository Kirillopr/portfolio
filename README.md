# portfolio
# Портфолио аналитика данных

Репозиторий с практическими проектами, демонстрирующими навыки работы с данными, автоматизации расчётов, прогнозирования и визуализации.

## 📂 Проекты

### ✅ Excel — автоматизация расчёта цен поставок

**Статус:** готово

Автоматизация расчёта актуальных цен товаров с учётом схем поставки, региональных и городских цен, а также индивидуальных условий для отдельных городов.

**Что реализовано:**
- Обработка и преобразование данных с помощью Power Query.
- Автоматизация расчётов с использованием ВПР, вложенных ЕСЛИ и ПОИСКПОЗ.
- Расчёт процентного изменения цен по городам.
- Создание интерактивного мини-дашборда в Excel со срезом для фильтрации по товарам.

### 🚧 Excel — прогнозирование

**Статус:** в разработке

Проект по прогнозированию показателей на основе исторических данных. Цель — продемонстрировать подход к анализу динамики, выбору метода прогнозирования и оценке точности результатов.

### 🚧 Power BI — интерактивный дашборд

**Статус:** в разработке

Интерактивный дашборд для визуализации ключевых показателей, анализа данных в различных разрезах и выявления закономерностей с помощью фильтров и визуальных элементов.

### 🚧 SQL — анализ данных

**Статус:** в разработке

Практические SQL-запросы для извлечения, объединения и анализа данных с использованием фильтрации, агрегации, JOIN, подзапросов и оконных функций.

## 🛠 Инструменты

- **Excel:** формулы, автоматизация расчётов, Power Query, интерактивная аналитика.
- **SQL:** запросы для обработки и анализа данных.
- **Power BI:** визуализация данных и создание интерактивных дашбордов.
- **Методы прогнозирования:** анализ исторических данных и оценка точности прогнозов.

## 🎯 Цель портфолио

Продемонстрировать практические навыки решения аналитических задач: от подготовки и обработки данных до расчётов, прогнозирования и визуализации результатов.

*Примечание: при публикации проектов используются данные, допустимые для публичного раскрытия. Конфиденциальная корпоративная информация не размещается.*
