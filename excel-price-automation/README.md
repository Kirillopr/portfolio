# Автоматизация расчёта цен поставок в Excel

## О проекте

Excel-проект по автоматизации расчёта актуальных цен на товары с учётом логистических схем поставки, региональных и городских цен, а также индивидуальных договорённостей для отдельных городов.

## Бизнес-задача

Поставщик использует комбинированную схему поставок: часть городов обслуживается через распределительный центр (РЦ), а в другие города товары поставляются напрямую.

Для отдельных городов действуют специальные условия ценообразования. Необходимо определить корректную цену каждого товара для каждого города и проанализировать изменение цен относительно исходных значений.

## Реализация

**1. Обработка данных**
- Подготовка и преобразование исходной выгрузки с помощью Power Query.
- Поиск необходимых значений и сопоставление данных по городам.
- Применение бизнес-правил для определения актуальной цены.

**2. Автоматизация расчётов**
- Использование ВПР, вложенных ЕСЛИ и ПОИСКПОЗ.
- Реализация логики выбора цены в зависимости от города и наличия установленной городской цены.
- Расчёт изменения цены в процентах относительно исходного значения.

**3. Интерактивный дашборд**
- Создание мини-дашборда непосредственно в Excel.
- Добавление среза для фильтрации по товару.
- Возможность просматривать процент изменения цены в разрезе городов для выбранного товара.

## Используемые инструменты

- Microsoft Excel
- ВПР (VLOOKUP)
- Вложенные ЕСЛИ (IF)
- ПОИСКПОЗ (MATCH)
- Power Query
- Сводные таблицы и срезы Excel — если использованы при создании дашборда

## Результат

Создана Excel-книга, объединяющая обработку исходных данных, автоматизированный расчёт цен по заданным бизнес-правилам и интерактивный анализ изменений в разрезе городов и товаров.

Проект демонстрирует навыки работы с большими табличными данными, реализации бизнес-логики в Excel и создания интерактивных инструментов для анализа.

## Конфиденциальность

Для публичной демонстрации используются синтетические данные. Исходные корпоративные данные и конфиденциальные коммерческие условия не раскрываются.
